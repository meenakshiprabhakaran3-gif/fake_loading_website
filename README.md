## Project Description

**Loadingo** is a fun, interactive website that simulates a dynamic loading process using HTML, CSS, and JavaScript.

It features an animated progress bar, changing loading messages, and an unexpected humorous outcome. The project turns the normally frustrating experience of waiting for something to load into an entertaining and engaging experience.

## The Problem (that doesn't exist)

Users often experience uncertainty and frustration while waiting for digital processes to complete, without knowing the actual progress or expected completion time.

## The Solution (that nobody asked for)

Actually, the system doesn't solve anything.

It simply makes you wait until **99%** and then wastes your time. 💀

That's the whole point of **Loadingo**!
